# Nexo Tiertagger

A Fabric mod (Minecraft 1.21.11) that shows each player's tier from the Nexo tierlist in their nametag and the player list, e.g. `HT3 | PlayerName`.

Gamemodes: NeliSMP, Vanilla (not counted in points yet), Sword and Triathlon.

`/nexotiers <player>` opens the player's profile (skin, global rank, title, points and tiers).

Based on [TierTagger](https://github.com/mctiers-dev/TierTagger) by uku and netiyiy, licensed under MPL-2.0.

Requires Fabric API and ukulib. Build with `./gradlew build` (JDK 21); the jar ends up in `build/libs/`.
